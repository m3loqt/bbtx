These are **historical observations supplied by the project owner** from Google Search Console and GA4. They were not re-pulled or recalculated from the repository. Use them as the "before" picture for Batch 1; do not treat them as current values, and do not read them as proof of how many real inquiries the site has produced.

**Reporting caveat.** `BBTX` is also a stock ticker, so impressions for the exact query `bbtx` should not automatically be counted as consulting-brand discovery. Report that query separately from relevant service-related searches. Do not derive an "exact nonbranded total" by subtracting visible query rows from the total: Search Console anonymizes some low-volume queries, so the remainder is not a clean nonbranded number.
